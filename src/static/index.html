OVARP runs studies with a conversational virtual agent. You script the agent's persona, let a participant talk to it on their own device, steer it live if you need to, and take away a timestamped log of everything that happened. Every tab below is one step of that.

  1. Build the agent in LLM Playground: pick the provider and voice, write the prompt or apply a persona, then talk to it yourself to hear how it responds.
  2. Save it as a persona in Profiles so you can switch between experimental conditions in one click, and reuse them across sessions.
  3. Run the session in Study Session: enter a Participant ID, press Start, and drop Event Markers as things happen. You can reclassify a marker or add notes afterwards.
  4. Intervene when you need to from WoZ Control: make the agent gesture, change emotion or say an exact line. It is also where you find the address the participant's client connects to.
  5. Collect the feedback in Surveys: send SUS, UEQ or your own questions to the participant's phone, then export everything as CSV.

Connect the published Web Client (Unity WebGL on Vercel):
  1. Set a real API key in .env, then start the server so it's reachable on the network: uvicorn src.main:app --host 0.0.0.0 --port 8000.
  2. In a second terminal, open a tunnel: cloudflared tunnel --url http://localhost:8000.
  3. Take the printed https://<random>.trycloudflare.com URL and swap https:// for wss://.
  4. Paste wss://<random>.trycloudflare.com/ws/client/web_01 into the "OVARP server" field on the web client.
Plain ws://localhost does not work from the HTTPS-hosted client: the browser blocks it silently (no Mixed Content warning), so it just times out.

How keys are stored
Encryption at rest
Checking…

Saved keys go to provider_keys.yaml, which is git-ignored. Set OVARP_SECRET_KEY in .env and they are encrypted with it; without that key they are written in plain text, exactly as .env would hold them.

A key is never included in a status response. Show asks the server for it explicitly. Set OVARP_ACCESS_TOKEN as well before exposing this console through a tunnel.
