💡 Getting Started — Quick guide for new users ▼
  1. Configure the LLM provider, system prompt, and voice in the LLM Playground tab, then click 💾 Save & Apply.
  2. Set up a profile in the 👤 Profiles tab — or select an existing one and click Apply Profile to load a pre-built persona.
  3. Run a study in 🧪 Study Session — enter a Participant ID, hit ▶ Start, and use Event Markers to annotate key moments.
  4. Control the agent live via 🎮 Remote Agent Control — trigger emotions, actions, and gestures in real time.
