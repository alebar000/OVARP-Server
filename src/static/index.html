Open Virtual Agent Research Platform (OVARP)
[INFO] Getting Started click to expand
  1. Configure the LLM provider and voice in the LLM Playground tab, then click Save & Apply.
  2. Set up a profile in the Profiles tab and click Apply Profile to load a persona.
  3. Run a study in Study Session: enter a Participant ID, press Start, and use Event Markers to annotate moments.
  4. Control the agent live via WoZ Remote Live Agent Control: trigger emotions, actions, and gestures in real time.
